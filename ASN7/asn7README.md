# Description of Project
This project is a measurement convert for the units inches and meters
The program allows a user to input a number, allowing them to conver this number into either: inches to meters, meters to inches


# How to Run
Install PySide6, python

1. Place asn7.py and house.png into the same folder
2. In a terminal, run python asn7.py while in it's directory
2a. In Python IDLE, open the file and run.
